# Industrial Automation PLC Lab

A collection of PLC and industrial automation projects developed using ABB Automation Builder and CoDeSys.

The projects cover IEC 61131-3 programming, reusable function blocks, industrial sensor processing, machine control logic, and Modbus RTU communication.

## Projects

### Analog Sensor Scaling
Reusable PLC function for converting raw analog input values into engineering units using Structured Text and Ladder Diagram.

### PLC Homing Function Block
Reusable homing logic for multiple machine axes using IEC 61131-3 function blocks, edge detection, limit switches, and state handling.

### Modbus RTU Slave
PLC implementation of Modbus RTU frame parsing and response handling, including CRC validation, holding-register access, and function codes 03 and 16.
